# SIT317 Project Landing Page

A landing page for a product my team is working on in SIT317 IT Innovations & Entrepreneurship at Deakin University,
Trimester 2 2026.

## Credits

- **Banner image:** [PixelShot](https://pixel-shot.com/showcase/i-11152110-0/group-of-students-studying-on-floor-at-university-top-view)
- **Fonts:** [Quicksand by Andrew Paglinawan](https://fonts.google.com/specimen/Quicksand) and [Gochi Hand by HT Fonts](https://fonts.google.com/specimen/Gochi+Hand)
- **Icons:** [Bootstrap Icons](https://icons.getbootstrap.com/)
- The page is built as a small [Vue.js](https://vuejs.org/) app, with [unplugin-vue-markdown](https://www.npmjs.com/package/unplugin-vue-markdown) to allow writing the content in Markdown files
- Much of the foundational SCSS code and some of the Vue component code is derived from my own previously developed library, [Comet Components](https://www.github.com/doubleedesign/comet-components)
- I used [Tippy.js](https://atomiks.github.io/tippyjs/) for the styled, animated tooltips
- To generate the boilerplate for each Vue component, I used a tool I had developed previously - [generate-vue-cli](https://www.npmjs.com/package/generate-vue-cli)
- The logo was designed by team member Passion Nguyen
- I used [ColorSpace](https://mycolor.space/?hex=%236C66A2&sub=1) to help select the rest of my colour palette based on the logo's colours.
